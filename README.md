### 🦁 Smart Zoo Navigator
![Category](https://img.shields.io/badge/Category-Web%20App%20%7C%20Navigation-24c6dc?style=flat-square)
![Deployed](https://img.shields.io/badge/Deployed%20on-Vercel-000000?style=flat-square&logo=vercel)

A responsive web app that helps visitors explore a zoo with ease. Users pick their zoo, browse an interactive map, and move through the app using a simple bottom navigation bar, so finding animals, paths and facilities takes seconds instead of guesswork.

**Highlights**
- Zoo selection flow as the landing experience
- Interactive map and easy in-app navigation
- Mobile-friendly design with a bottom navigation bar

🔗 **[Live Demo](https://myzoo-navigator.vercel.app)** • 💻 **[Source Code](https://github.com/urfavsidhu/myzoo-navigator)**

### ✅ Daily Habit Tracker
![Category](https://img.shields.io/badge/Category-Productivity%20%7C%20Web%20App-24c6dc?style=flat-square)
![Deployed](https://img.shields.io/badge/Deployed%20on-Vercel-000000?style=flat-square&logo=vercel)

A clean and simple habit tracking app that helps you build consistency. Add your daily habits, mark them done each day, and keep your streak going, so building a routine feels rewarding instead of overwhelming.

**Highlights**
- Track daily habits in one place
- Simple, distraction-free interface
- Works smoothly on both mobile and desktop

🔗 **[Live Demo](https://daily-habit-tracker-teal-three.vercel.app)**
